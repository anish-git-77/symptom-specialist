## 🚀 Features

- **Free-text symptom input** — no dropdowns, just natural language
- **Top 3 specialist recommendations** with confidence scores
- **Disease descriptions** pulled from real medical dataset
- **Precaution tips** for each predicted condition
- **Emergency alerts** for critical conditions (heart attack, stroke, etc.)
- **"What to tell the doctor"** checklist

---

`Python` `scikit-learn` `TF-IDF` `Logistic Regression` `Streamlit` `Pandas` `NumPy`

## 📁 Project Structure

```
symptom-specialist/
├── data/                   ← place Kaggle CSVs here
│   ├── dataset.csv
│   ├── symptom_Description.csv
│   ├── symptom_precaution.csv
│   └── Symptom-severity.csv
├── models/
│   └── specialist_model.pkl   ← auto-generated by train_model.py
├── app.py                  ← Streamlit web app
├── train_model.py          ← train & save model
├── load_data.py            ← Kaggle CSV loader
├── specialist_map.py       ← disease → specialist mappings
└── requirements.txt
```

## ⚙️ Setup & Run

```bash
# 1. Clone
git clone https://github.com/yourusername/symptom-specialist
cd symptom-specialist

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download Kaggle dataset
# Go to: https://www.kaggle.com/datasets/itachi9604/disease-symptom-description-dataset
# Place the 4 CSV files inside the data/ folder

# 4. Train the model (run once)
python train_model.py

# 5. Launch the app
streamlit run app.py
```
